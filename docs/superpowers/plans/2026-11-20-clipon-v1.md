# ClipOn v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ClipOn`, an ultra-lightweight, zero-bloat Rust clipboard launcher daemon for Ubuntu 22.04 LTS (Wayland / XWayland) featuring arbitrary double-tap key triggering, instant frameless popup with keyboard selection (`↑`/`↓`+`Enter`, `1-9`/`a-z`), text/file-path/image support, minimal GUI settings with autostart toggle, and GNOME top-bar system tray indicator.

**Architecture:** Single native Rust binary (`clipon`) operating as a background daemon with zero C-library build dependencies. Uses `x11rb` (pure Rust XFixes) for event-driven clipboard monitoring & selection ownership, `evdev` (pure Rust) for global double-tap detection + `/dev/uinput` virtual keyboard auto-paste (with X11/`xdotool` fallbacks), `ksni` (pure Rust DBus StatusNotifierItem) for the GNOME top-bar tray icon, UNIX domain socket IPC for single-instance & CLI triggers, and a persistent Show/Hide `eframe`/`egui` window for sub-millisecond popup display and minimal settings.

**Tech Stack:** Rust 2021 (`rustc 1.94.1`), `eframe 0.31`, `x11rb 0.14`, `evdev 0.13`, `ksni 0.3` (`blocking`, `async-io`), `image 0.25` (`png`), `serde 1` + `toml 0.8`, `directories 5`.

## Global Constraints

- 対象環境は Ubuntu 22.04 LTS (GNOME on Wayland + XWayland `DISPLAY=:0`)。単一バイナリ `clipon` ＋ `config.toml` のみで動作すること。
- コード内のコメントおよび Docstring は**必ず日本語**で記述すること（構文・識別子・技術用語は英語維持）。
- ゼロ贅肉原則: クラウド同期、色・テーマ着せ替え設定、タグ管理、重い検索エンジンは一切実装しないこと (REQ-1, REQ-5)。
- すべての公開ロジックは TDD（RED → GREEN → REFACTOR）でテストを先に書き、`cargo test` および `cargo clippy --all-targets -- -D warnings` が警告ゼロで通ること。
- REQ-1: 設定画面から押下キーを検知して呼び出しキーバインド（例: `Shift` 2回）を設定可能。色・装飾設定は禁止。
- REQ-2: クリップボード履歴をメモリ上のリングバッファで保持し、件数 `max_items` は設定可能（デフォルト 25）。
- REQ-3: `↑` / `↓` + `Enter` および `1`〜`9`, `a`〜`z` の単打キーで選択可能。
- REQ-4: 選択時にクリップボードへ転送し、直前ウィンドウへ `paste_key`（デフォルト `Ctrl+v`、変更可能）を自動送出可能（`auto_paste` ON/OFF）。
- REQ-6: テキストに加え、ファイルコピー（`📄 filename`、`file_mode = "path" | "file"`）および画像コピー（`🖼️ [画像 WxH]`、`image_mode = "image" | "path"`）に対応。
- REQ-7: 設定画面のチェックボックスで `~/.config/autostart/clipon.desktop` の作成・削除を切り替え可能。
- REQ-8: Ubuntuトップバーにシステムトレイアイコン常駐、メニュー項目は「表示」「設定」「終了」の3つ。
- `config.toml` スキーマは `SPECIFICATION.md` Section 4 に完全準拠（`[trigger]`, `[history]`, `[paste]`, `[media]`）。

## File Structure

- `Cargo.toml` — 依存クレート定義（純Rust・C開発ヘッダ非依存）
- `src/lib.rs` — モジュール公開エントリ
- `src/config.rs` — `AppConfig`（`config.toml` 読込/保存/バリデーション）および `~/.config/autostart/clipon.desktop` 管理
- `src/history.rs` — `ClipContent`（Text / FilePaths / Image）、`ClipItem`、`HistoryStore` リングバッファ、URIデコード、画像キャッシュ、ショートカット文字マッピング
- `src/trigger.rs` — `TriggerKey`、`KeyEventKind`、`TriggerDetector`（N回タップ・誤爆防止・単発コンボ判定の純粋ステートマシン）
- `src/paste.rs` — `PasteShortcut` パーサ、`UinputPaster`（`/dev/uinput` 仮想キーボード送出＋`xdotool`フォールバック）
- `src/ipc.rs` — `IpcCommand`、`IpcServer` / `send_command`（`$XDG_RUNTIME_DIR/clipon.sock` 経由の多重起動防止＆即時トリガー）
- `src/clipboard.rs` — `x11rb` + `XFixes` イベント駆動クリップボード監視、`UTF8_STRING` / `text/uri-list` / `image/png` 取得（INCR対応）、所有権提供、`query_pointer`
- `src/keyhook.rs` — `evdev` キーボード自動検出・監視スレッド＋X11キーマップフォールバック＋ライブキー録音チャネル
- `src/tray.rs` — `ksni` (StatusNotifierItem) 内蔵ARGBアイコン生成＆「表示」「設定」「終了」メニュー
- `src/gui.rs` — `eframe`/`egui` 常駐Show/Hideポップアップ＋装飾なしシンプル設定画面＋日本語フォント自動読込
- `src/main.rs` — CLIオプション処理（`--toggle` / `--settings` / `--quit`）とデーモン全体の配線
- `scripts/setup-input-access.sh` — `evdev` 読み取り権限（udevルール / `input`グループ）のワンショット補助スクリプト

- [ ] **Step 3: 最小実装（GREEN）を `src/trigger.rs` に記述**

- 単一キーN回タップモード (`modifiers.is_empty()` かつ `tap_count >= 2`):
  - `held_keys: HashSet<TriggerKey>` で現在押下中キーを追跡（リピート `pressed=true` を無視）。
  - `main_key` 押下時: 他キーが押されていれば `tainted = true`、そうでなければ `press_started_at = Some(now_ms)`, `tainted = false`。
  - `main_key` 押下中に別キーが押されたら `tainted = true`, `tap_streak = 0`。
  - `main_key` 解放時: `!tainted` かつ `now_ms - press_started_at <= MAX_TAP_HOLD_MS (500)` なら有効タップ。前回有効タップ解放時刻との差が `interval_ms` 以内なら `tap_streak += 1`、超過なら `tap_streak = 1`。`tap_streak >= tap_count` で `tap_streak = 0; return true;`。
- 単発/コンボモード (`!modifiers.is_empty()` または `tap_count == 1`):
  - `pressed == true` かつ 新規押下（リピートでない）かつ `key == main_key` かつ 全ての `modifiers` が `held_keys` に含まれる場合に `true` を返す。
